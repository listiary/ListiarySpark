## Spark 0.2 - 1wipe_database

Delete all the contents from a database - as means to uninstall the wiki.

```
usage (bash) - output to console                            php 1wipe_database.php
usage (bash) - output to file                               php 1wipe_database.php > "output.txt"
usage (bash) - append to file                               php 1wipe_database.php >> "output.txt"
usage (bash) - capture errors to file                       php 1wipe_database.php 2> "errors.txt"
usage (bash) - append errors to file                        php 1wipe_database.php 2>> "errors.txt"
usage (bash) - capture output and errors to file            php 1wipe_database.php > "all_output.txt" 2>&1
usage (bash 4+) - capture output and errors to file         php 1wipe_database.php &> "all_output.txt"
```
