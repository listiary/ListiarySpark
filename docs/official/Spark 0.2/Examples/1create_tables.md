## Spark 0.2 - 1create_tables

Create the needed tables for the wiki in the database provided in the `_config.php` file.

```
usage (bash) - output to console                            php 1create_tables.php
usage (bash) - output to file                               php 1create_tables.php > "output.txt"
usage (bash) - append to file                               php 1create_tables.php >> "output.txt"
usage (bash) - capture errors to file                       php 1create_tables.php 2> "errors.txt"
usage (bash) - append errors to file                        php 1create_tables.php 2>> "errors.txt"
usage (bash) - capture output and errors to file            php 1create_tables.php > "all_output.txt" 2>&1
usage (bash 4+) - capture output and errors to file         php 1create_tables.php &> "all_output.txt"
```
