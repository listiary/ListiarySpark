## Spark 0.5 - help

Output the help message.
<br><br>
There are different verbs for this command: `help`, `h`, `-h`, `-help`, `--help`
<br><br>


## Command Syntax
`h [PRESENTATION_FLAGS]`<br>
`PRESENTATION_FLAGS` - common presentation flags for the SparkCli.<br>
For more info on presentation flags, check the [manual].
<br><br>



## Examples
`php spark.php h`<br>
Output the help message.
<br><br>
`php spark.php h theme=DEFAULT`<br>
Output the help message, with presentation flags
<br><br>
`php spark.php h -hb theme=DEFAULT`<br>
Output the help message, with presentation flags
<br><br>
`php spark.php h -auto -hb theme=DEFAULT`<br>
Output the help message, with presentation flags
<br><br>
