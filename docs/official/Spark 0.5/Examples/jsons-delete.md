## Spark 0.5 - jsons-delete

Delete all the compiled JSON files in the database.



## Command Syntax
`jsons-delete [PRESENTATION_FLAGS]`<br>
`PRESENTATION_FLAGS` - common presentation flags for the SparkCli.<br>
For more info on presentation flags, check the [manual].
<br><br>



## Examples
`php spark.php jsons-delete`<br>
Delete all the JSON files in the database.
<br><br>
`php spark.php jsons-delete theme=DEFAULT`<br>
Delete all the JSON files in the database, with presentation flags.
<br><br>
`php spark.php jsons-delete -hb theme=DEFAULT`<br>
Delete all the JSON files in the database, with presentation flags.
<br><br>
`php spark.php jsons-delete -auto -hb theme=DEFAULT`<br>
Delete all the JSON files in the database, with presentation flags.
<br><br>
