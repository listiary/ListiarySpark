## Spark 0.5 - NONE

When ran without a command, spark displays a simple message, telling us in few lines what spark is,
and encouraging us to run the help command, for more info.<br>
When ran with a wrong command, we see an error message, letting us know the command is wrong, and the standard help message.


## Command Syntax
` [PRESENTATION_FLAGS]`<br>
`PRESENTATION_FLAGS` - common presentation flags for the SparkCli.<br>
For more info on presentation flags, check the [manual].
<br><br>



## Examples
`php spark.php`<br>
Run SparkCli without a command.
<br><br>
`php spark.php theme=DEFAULT`<br>
Run SparkCli without a command, with presentation flags.
<br><br>
`php spark.php -hb theme=DEFAULT`<br>
Run SparkCli without a command, with presentation flags.
<br><br>
`php spark.php -auto -hb theme=DEFAULT`<br>
Run SparkCli without a command, with presentation flags.
<br><br>
