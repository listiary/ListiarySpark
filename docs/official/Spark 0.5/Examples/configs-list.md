## Spark 0.5 - configs-list

List all the configs in the `_configs` folder.



## Command Syntax
`configs-list [PRESENTATION_FLAGS]`<br>
`PRESENTATION_FLAGS` - common presentation flags for the SparkCli.<br>
For more info on presentation flags, check the [manual].
<br><br>



## Examples
`php spark.php configs-list`<br>
List all the configs in the `_configs` folder.
<br><br>
`php spark.php configs-list theme=DEFAULT`<br>
List all the configs in the `_configs` folder, with presentation flags.
<br><br>
`php spark.php configs-list -hb theme=DEFAULT`<br>
List all the configs in the `_configs` folder, with presentation flags.
<br><br>
`php spark.php configs-list -auto -hb theme=DEFAULT`<br>
List all the configs in the `_configs` folder, with presentation flags.
<br><br>
